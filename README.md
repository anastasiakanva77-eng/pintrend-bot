# StyleBot MVP — Telegram + MAX

Один каталог товаров для двух ботов.

## Что умеет
- Пользователь пишет артикул.
- Бот ищет товар.
- Отправляет до 10 фотографий образов.
- Показывает кнопку «Посмотреть товар на WB».
- Показывает кнопку «Ввести другой артикул».
- Есть простая закрытая веб-админка `/admin`, где можно добавлять/обновлять товары и фотографии.
- Telegram и MAX используют одну и ту же базу.

## 1. Подготовка
Нужны:
- Telegram Bot Token от @BotFather.
- MAX Bot Token из платформы MAX для партнёров.
- Сервер с публичным HTTPS-доменом.
- Python 3.11+.

Никому не отправляйте токены. Вставляйте их только в переменные окружения на своём сервере.

## 2. Запуск локально
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Экспортируйте переменные окружения или используйте менеджер окружения вашего хостинга.

Запуск:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

## 3. Подключение webhook
После того как BASE_URL доступен по HTTPS:
```bash
python setup_webhooks.py
```

## 4. Админка
Откройте:
`https://ВАШ-ДОМЕН/admin`

Войдите логином/паролем из ADMIN_USER / ADMIN_PASSWORD.

Для товара укажите:
- Артикул — то, что вводит покупатель.
- Дополнительные варианты артикула (необязательно).
- Название.
- Ссылку WB.
- От 1 до 10 изображений.

Если добавить товар с тем же артикулом повторно, карточка обновится.

## 5. Как выглядит сценарий
Пользователь:
`J130`

Бот:
`Нашла ваш товар 🤍 Вот готовые образы с ним.`

Далее фотографии и кнопки:
- `Посмотреть товар на WB`
- `Ввести другой артикул`

## Важно про MAX
Production-интеграция MAX должна принимать события по HTTPS Webhook. MAX использует домен API:
`https://platform-api2.max.ru`

Проверьте на сервере актуальное доверие к сертификатам, требуемым MAX.

## Самый простой запуск на Railway

1. Загрузите содержимое этой папки в новый GitHub-репозиторий.
2. Railway → **New Project** → **Deploy from GitHub repo** → выберите репозиторий.
3. В сервисе Railway откройте **Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_WEBHOOK_SECRET` — придумайте длинную строку из букв/цифр/`_`/`-`.
   - `ADMIN_USER` — ваш логин для админки.
   - `ADMIN_PASSWORD` — сложный пароль.
   - `MAX_BOT_TOKEN` и `MAX_WEBHOOK_SECRET` пока можно оставить пустыми.
4. В **Settings → Networking** нажмите **Generate Domain**.
   `BASE_URL` вручную задавать не обязательно: приложение использует `RAILWAY_PUBLIC_DOMAIN`.
5. Добавьте Railway **Volume** к этому сервису. Подойдёт mount path `/app/storage`.
   Приложение автоматически увидит `RAILWAY_VOLUME_MOUNT_PATH` и будет хранить там базу и фотографии.
6. После успешного deploy откройте:
   `https://ВАШ-ДОМЕН/admin`
7. В админке нажмите **«Подключить Telegram webhook»**.
8. Добавьте тестовый артикул и 1–10 фото.
9. Откройте `@pintrend_bot`, нажмите Start и введите артикул.

### Почему нужен Volume
SQLite-база и загруженные фотографии должны переживать новые deploy. Railway Volume даёт постоянное файловое хранилище.
